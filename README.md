# Installation

Icons and wallpapers are available directly from this repository.

* In a terminal, clone the repository:

```sh
git clone https://github.com/Nitrux/luv-icon-theme.git
cd luv-icon-theme
```

* Install system-wide:

```sh
sudo cp -r Luv /usr/share/icons/
sudo cp -r Wallpapers/* /usr/share/wallpapers/
```

* Install for your user only:

```sh
mkdir -p ~/.local/share/icons ~/.local/share/wallpapers
cp -r Luv ~/.local/share/icons/
cp -r Wallpapers/* ~/.local/share/wallpapers/
```
